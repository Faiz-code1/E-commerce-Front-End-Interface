# E-commerce Front-End Interface (Amazon Clone)

A responsive front-end clone of the Amazon e-commerce website built using HTML and CSS.

## 🚀 Live Demo
[View Live Project](https://faiz-code1.github.io/E-commerce-Front-End-Interface/)

## 🛠️ Tech Stack
* **HTML5**
* **CSS3** (Flexbox, Media Queries)
* **Font Awesome Icons**

## ✨ Features
* Responsive navigation bar and product showcases
* Mobile-friendly side-scrolling panel
* Clean UI design matching the e-commerce layout
* Sign-in and product interface pages
